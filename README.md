# 1946, 제네바 문서고의 비밀

중학교 역사② 세계대전 단원(1차 세계대전 · 베르사유 체제 · 대공황과 전체주의 · 2차 세계대전) 개인별 방탈출 수업 게임.

학생은 닉네임과 조사관 아바타로 입장해 국제 연맹 문서고 지도를 돌아다닙니다. 경비원의 손전등을 피해 숨은 보관함 4개를 찾고, 사건 연도(1914·1919·1929·1939)로 자물쇠를 열어 쏟아진 서류·사진을 견주어 퀴즈를 풀면 열쇠를 얻습니다. 열쇠 4개로 지하 금고(1945)를 열고 새 기구에 전할 한 문장을 남기면 탈출합니다.

## 화면
- `#/` 학생 화면 (QR 주소 `?c=수업코드&m=분&g=경비원수&s=빠르기`)
- `#/teacher` 교사 화면 (처음 PIN 1946): 설정, 정답 미리 보기
- `#/board` 실시간 진행판: 수업 코드 만들기, 학생 위치 지도, +5분, 통행증 +1

## 규칙
- 통행증 3장. 손전등 빛에 비치거나 경비원과 부딪히면 1장 잃고 로비로 돌아갑니다. 그림자 속에서는 들키지 않습니다.
- 다 잃으면 1분 쉬고 1장으로 다시 시작(열쇠·수첩은 유지).
- 자물쇠를 3번 틀리면 경비원이 소리를 듣고 달려옵니다.

## 개발
```
npm install
npm run dev
npm run build   # dist/
```
- 내용: `src/data/game.js` (자료 카드, 퀴즈, 지도 벽·가구, 경비원 길)
- 그림: `public/art/` (Canva 제작), 도입 영상: `public/media/intro.mp4`
- 실제 사진을 넣으려면 `public/sources/<이름>.jpg` (munitions, versailles, breadline, auschwitz)
- 진행판 서버는 역사교사 아카이브의 `/api/sechaek`(Cloudflare D1)를 함께 씁니다. 서버가 없으면 혼자 하기만 됩니다.
